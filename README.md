# بک‌اند فروشگاه «آوای انعکاس»

این پروژه، بک‌اند فروشگاه صوتی «آوای انعکاس» است که با **Django** و **Django REST Framework** نوشته شده است.
یک REST API کامل برای محصولات، سفارش‌ها، مشتریان و مقالات دارد و یک پنل ادمین جنگو هم به همراه آن می‌آید.
هدف این راهنما این است که روی یک سیستم ویندوزیِ تمیز، از صفر تا اجرا جلو برویم.

> این مخزن فقط بک‌اند است. پروژه‌ی فرانت (React + Vite) جداگانه تحویل‌تان می‌شود و در بخش «اتصال به فرانت» نحوه‌ی وصل کردنش توضیح داده شده است.

```
AvaProject-Backend/

├── Ava/                   ← تنظیمات پروژه (settings.py و urls.py)

└── media/                 ← محل ذخیره عکس و ویدیوهای آپلودی (بعداً خودکار ساخته می‌شود)
```

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- **پایتون نسخه ۳.۱۲ یا بالاتر** (۳.۱۳ و ۳.۱۴ هم خوب است)

### اگر پایتون نصبتان نیست، این‌طور نصبش کنید

1. به سایت رسمی پایتون بروید: `https://www.python.org/downloads/`
2. دکمه‌ی سبز **Download Python** را بزنید (فایل نصبی ویندوز را می‌گیرد).
3. فایل دانلودشده را اجرا کنید.
4. در اولین صفحه‌ی نصب، تیک **«Add python.exe to PATH»** را **حتماً** بزنید (مهم است).
5. روی **Install Now** کلیک کنید و صبر کنید تا تمام شود.
6. پنجره‌ی Command Prompt (CMD) را ببندید و یک پنجره‌ی جدید باز کنید تا تغییرات PATH اعمال شود.
7. این دستور را بزنید تا مطمئن شوید پایتون نصب شده:

```
python --version
```

اگر خروجی چیزی شبیه `Python 3.14.7` دیدید یعنی پایتون آماده است.

> نکته: اگر دستور بالا خطای «python is not recognized» داد، دستور زیر را امتحان کنید:
> ```
> py --version
> ```
> و در تمام دستورهای بعدی این راهنما، به‌جای `python` از `py` استفاده کنید.

## قدم ۱ — گرفتن کد پروژه از گیت‌هاب

یک پوشه خالی بسازید (مثلاً `C:\Projects`) و داخلش این دستور را بزنید:

```
git clone https://github.com/sasm110313/AvaProject-Backend.git
```

سپس وارد پوشه‌ی پروژه شوید:

```
cd AvaProject-Backend
```

> اگر گیت نصب ندارید، از وب‌سایت گیت‌هاب، دکمه‌ی سبز **Code → Download ZIP** را بزنید و فایل ZIP را اکسترکت کنید، بعد با CMD وارد پوشه‌ی اکسترکت‌شده شوید.

⚠️ **خیلی مهم:** تمام دستورهای بعدی باید از داخل همان پوشه‌ای اجرا شوند که فایل `manage.py` داخلش است.
با این دستور چک کنید که سر جایتان هستید:

```
dir manage.py
```

اگر فایل `manage.py` را نشان داد، یعنی جای درستی هستید.

## قدم ۲ — ساخت محیط مجازی (venv)

محیط مجازی یک پوشه‌ی خلوت است که کتابخانه‌های پروژه فقط داخلش نصب می‌شوند و به بقیه‌ی ویندوزتان دست نمی‌زنند.

ساختش:

```
python -m venv venv
```

فعال‌سازی (با فرض استفاده از CMD):

```
venv\Scripts\activate
```

بعد از این دستور، باید اول خط فرمان عبارت `(venv)` ظاهر شود، مثل:

```
(venv) C:\Projects\AvaProject-Backend>
```

به این معنی است که محیط مجازی روشن است.

> **اگر دوست ندارید از venv استفاده کنید:** این مرحله را رد کنید و مستقیم بروید سراغ نصب نیازمندی‌ها.
> نصب بدون venv هم کار می‌کند، فقط کتابخانه‌ها روی خود پایتون ویندوز نصب می‌شوند.

## قدم ۳ — نصب نیازمندی‌ها

اول ابزار `pip` (مدیر نصب کتابخانه‌ها) را به‌روزرسانی کنید:

```
python -m pip install --upgrade pip
```

بعد همه‌ی کتابخانه‌های پروژه را با یک دستور نصب کنید:

```
python -m pip install -r requirements.txt
```

کتابخانه‌های نصب‌شده:

| کتابخانه | نسخه | کاربرد |
|---|---|---|
| Django | 6.0.7 | فریم‌ورک وب |
| djangorestframework | 3.18.0 | ساخت REST API |
| django-cors-headers | 4.9.0 | اجازه‌ی ارتباط با فرانت از پورت دیگر |
| python-decouple | 3.8 | خواندن تنظیمات |

برای اطمینان از نصب درست، این را بزنید:

```
python -c "import django; print(django.get_version())"
```

باید عدد `6.0.7` را چاپ کند.

## قدم ۴ — آماده‌سازی دیتابیس

پروژه از دیتابیس خیلی ساده‌ای به نام SQLite استفاده می‌کند که یک فایل است و هیچ نصب جداگانه‌ای نمی‌خواهد.

این دستور جدول‌های دیتابیس را می‌سازد:

```
python manage.py migrate
```

حالا با این دستور **دیتای نمونه** بارگذاری کنید (۱۵ محصول، ۱۰ سفارش، ۸ مشتری، ۲ مقاله):

```
python manage.py seeddata
```

در پایان، برای پنل ادمین جنگو یک کاربر مدیر بسازید (نام کاربری و رمز دلخواه وارد کنید):

```
python manage.py createsuperuser
```

> این دستور سه سؤال می‌پرسد: username، email و password. رمز را دو بار وارد کنید. اگر رمز ساده بدهید، می‌پرسد «حتماً؟» که y بزنید.

## قدم ۵ — اجرای بک‌اند

پروژه را روی **پورت 4000** اجرا کنید (عدد 4000 مهم است چون فرانت دقیقاً به همین پورت وصل می‌شود):

```
python manage.py runserver 4000
```

باید چیزی شبیه این ببینید:

```
Starting development server at http://127.0.0.1:4000/
```

**این CMD را نبندید** — تا وقتی که دارید تست می‌کنید باید باز باشد.

## قدم ۶ — تست API و پنل ادمین

۵ نکته برای بررسی سلامت بک‌اند:

| کار | آدرس | نتیجه‌ی درست |
|---|---|---|
| لیست محصولات | `http://localhost:4000/api/products` | فهرست محصولات (JSON) |
| لیست سفارش‌ها | `http://localhost:4000/api/orders` | فهرست سفارش‌ها با کدهای `ORD-...` |
| لیست مشتریان | `http://localhost:4000/api/customers` | فهرست مشتریان با تعداد سفارش و مجموع خرید |
| لیست مقالات | `http://localhost:4000/api/articles` | فهرست مقالات |
| لیست دسته‌بندی‌ها | `http://localhost:4000/api/categories` | آرایه‌ای از نام دسته‌ها |

این آدرس‌ها را همین‌طوری در مرورگر باز کنید — چون خروجی JSON است، مستقیم می‌بینیدش.

پنل ادمین جنگو هم اینجاست:

```
http://localhost:4000/admin/
```

با همان username و رمز ساخته‌شده در قدم ۴ وارد شوید. هر تغییری در این پنل بدهید بلافاصله در همان فایل دیتابیس ذخیره می‌شود و در API دیده می‌شود.

## قدم ۷ — اتصال به فرانت (React/Vite)

معماری کار این‌طور است: **دو سرور هم‌زمان** باید روشن باشند.

| سرور | پورت | نقش |
|---|---|---|
| بک‌اند (Django) — هم‌حالا روشن کردیم | 4000 | ارائه‌ی API |
| فرانت (Vite/React) | 5173 | رابط کاربری که از API می‌خواند |

### ۷-۱) اجرای فرانت

پروژه‌ی فرانت در پوشه‌ی `Front/AvayEnekas` قرار دارد (که جداگانه تحویل‌تان داده می‌شود). داخل آن:

```
cd Front/AvayEnekas
npm install
npm run dev
```

حالا فرانت روی `http://localhost:5173` بالا آمده است (این CMD را هم نبندید).

صفحه‌ی پنل ادمین در فرانت:

```
http://localhost:5173/AdminPannel
```

### ۷-۲) روشن کردن API واقعی در فرانت

فرانت در این حالت به‌طور پیش‌فرض با **دیتای تستی** کار می‌کند. برای اینکه به بک‌اند واقعی وصل شود، یک فلگ را عوض کنید.

فایل زیر را باز کنید:

```
Front/AvayEnekas/src/Components/AdminPannel/Api.jsx
```

و روی خطی که می‌گوید:

```js
export const USE_MOCK_DATA = true;
```

مقدار `true` را به `false` تغییر دهید:

```js
export const USE_MOCK_DATA = false;
```

فایل را ذخیره کنید (Vite خودش صفحه را رفرش می‌کند، نیازی به ری‌استارت نیست).

آدرس API هم به‌صورت پیش‌فرض `http://localhost:4000/api` است که همان بک‌اند ماست و نیازی به تغییر ندارد (اگر پورت بک‌اند را عوض کردید، این‌جا هم عوض کنید).

### ۷-۳) تست اتصال

1. مطمئن شوید هر دو سرور روشن هستند (بک‌اند روی 4000 و فرانت روی 5173).
2. `http://localhost:5173/AdminPannel` را باز کنید. باید با دیتای واقعی بک‌اند (همان ۱۵ محصول، ۱۰ سفارش و...) پر شود.
3. در پنل یک محصول جدید بسازید یا حذف کنید.
4. بعد `http://localhost:4000/api/products` را در مرورگر باز کنید — همان تغییر را می‌بینید.

اجازه‌ی اتصال بین فرانت (پورت 5173) و بک‌اند (پورت 4000) از قبل در تنظیمات CORS فعال شده است، پس هیچ تنظیم اضافه‌ای لازم نیست.

> اگر برنامه‌ی فرانت را باز کنید ولی پنل ادمین با صفحه‌ی خطا و دکمه‌ی Retry مواجه شد، یعنی بک‌اند روشن نیست یا پورت درست نیست.

## عیب‌یابی

| خطا / علامت | علت | راه‌حل |
|---|---|---|
| `'python' is not recognized as an internal or external command` | پایتون به PATH اضافه نشده یا CMD را نبسته‌اید | از `py` استفاده کنید یا CMD را ببندید و دوباره باز کنید |
| `'pip' is not recognized` | `pip` در مسیر نیست | به‌جای `pip install ...` بنویسید `python -m pip install ...` |
| `No module named django` | نیازمندی‌ها نصب نشده‌اند یا venv روشن نیست | مطمئن شوید در اول خط فرمان `(venv)` می‌بینید، بعد `python -m pip install -r requirements.txt` |
| `You have 1 unapplied migration(s)` | migrate را نزده‌اید | `python manage.py migrate` |
| `Error: That port is already in use` یا خطای EADDRINUSE | پورت 4000 مشغول است | همه‌ی CMDهای قبلی را ببندید یا بک‌اند را روی پورت دیگر مثل `runserver 4001` اجرا کنید و `API_BASE_URL` را در فایل `Api.jsx` فرانت عوض کنید |
| page از فرانت دیتای خالی نشان می‌دهد / پیام خطای ارتباط با سرور | بک‌اند روشن نیست | CMD بک‌اند را چک کنید و دوباره `python manage.py runserver 4000` بزنید |
| مرورگر هنگام اولین اجرای سرور از شما مجوز فایروال می‌گیرد | فایروال ویندوز | روی **Allow access** کلیک کنید |

## نکات امنیتی (بعد از اینکه کار کرد)

- `SECRET_KEY` فعلی یک کلید پیش‌فرض برای توسعه است. قبل از گذاشتن سرور روی اینترنت، آن را عوض کنید (فایل `Ava/settings.py`).
- در حالت توسعه `DEBUG = True` است؛ برای استقرار واقعی باید `False` شود.
- رمز ادمینی که با `createsuperuser` ساختید را حفظ کنید و اگر پنل عمومی می‌شود، هر چند وقت یک‌بار عوضش کنید.
